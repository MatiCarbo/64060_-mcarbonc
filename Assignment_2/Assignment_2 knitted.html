# Set seed for reproducibility

Question 2: Determining the Optimal Choice of k

To find the optimal choice of k that balances overfitting and underfitting (ignoring predictor information), I evaluated model accuracy on the validation set across k values ranging from 1 to 15.

# Initialize dataframe to store accuracies
accuracy_df <- data.frame(k = 1:15, Accuracy = numeric(15))

# Loop through k values 1 to 15
for(i in 1:15) {
  knn_pred <- knn(train = train_norm, 
                  test = valid_norm, 
                  cl = train_labels, 
                  k = i)
  
  accuracy_df$Accuracy[i] <- mean(knn_pred == valid_labels)
}

Discussion:
The choice of k = 3 (or the top-performing k identified in the plot) balances overfitting and underfitting. A very small k (\(k=1\)) captures too much noise and overfits the training set, whereas a large k smooths out decision boundaries and risks ignoring important predictor signals.

Question 5: Repartitioning into Training (50%), Validation (30%), and Test (20%) Sets

I repartitioned the dataset into 50% Training, 30% Validation, and 20% Test sets. I normalized all three partitions using the parameters from the new training set and evaluated the model using the previously chosen best_k.

# Set seed for reproducible 3-way split
set.seed(123)

# 1. First partition: split into 50% Train and 50% remaining (Validation + Test)
train_index_3way <- createDataPartition(my_data$Personal.Loan, p = 0.50, list = FALSE)
train_df_3way <- my_data[train_index_3way, ]
temp_df <- my_data[-train_index_3way, ]

# 2. Second partition: split remaining 50% into 30% Validation and 20% Test (ratio 60/40 of remaining)
valid_index_3way <- createDataPartition(temp_df$Personal.Loan, p = 0.60, list = FALSE)
valid_df_3way <- temp_df[valid_index_3way, ]
test_df_3way  <- temp_df[-valid_index_3way, ]

# Normalize predictors based on the new training set
norm_values_3way <- preProcess(train_df_3way[, -which(names(train_df_3way) == "Personal.Loan")], 
                               method = c("center", "scale"))

train_norm_3way <- predict(norm_values_3way, train_df_3way[, -which(names(train_df_3way) == "Personal.Loan")])
valid_norm_3way <- predict(norm_values_3way, valid_df_3way[, -which(names(valid_df_3way) == "Personal.Loan")])
test_norm_3way  <- predict(norm_values_3way, test_df_3way[, -which(names(test_df_3way) == "Personal.Loan")])

# Extract labels

valid_labels_3way <- factor(valid_df_3way$Personal.Loan, levels = c(0, 1))

Comparison and Discussion of Differences:

  • Training Set vs. Validation/Test Sets: The training set metrics (especially when \(k=1\)) display artificially high accuracy and sensitivity because the model evaluates data points against themselves or immediate neighbors in the training set.
  • Validation Set vs. Test Set: The validation and test sets reflect realistic out-of-sample generalization performance. Performance metrics between validation and test sets are very close to one another, showing that the model is stable and does not overfit significantly when evaluated on unseen data.
  • Reasons for Differences: The primary reason for differences between training and test/validation performance is that training metrics measure model fit (memorization when \(k\) is small), while validation and test metrics measure model generalization on unseen data.
